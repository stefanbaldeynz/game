# Lightsaber sounds and blades (only on your computer)

The Weathertop duel uses Jedi Outcast's own lightsaber sounds (ignition, hum, swings, blocks, hits) and Force sounds (push, grip, lightning), and its blade pictures, when they're in this folder. Without them it uses its own made-up sounds and painted blades.

To fill it, with Jedi Knight II: Jedi Outcast installed, run:

```powershell
& C:\Users\Stefan\bfme\tools\Prep-Sabers.ps1
```

**Everything in this folder stays on your computer.** Git ignores it (only this README is in the repository). The files belong to Lucasfilm and Raven Software, so keep them for playing at home.
